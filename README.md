# Questroom Home Assistant
## Описание

Данный проект был предназначен для автоматизации квеста под названием "Терапия" (https://extrareality.by/quest/terapia). Основа проекта - Home Assistant на Raspberry 4, вся логика квеста сделана в Node-red. Node-red управляет железом (Arduino) в квесте по сети через MQTT, ардуины в квесте выступают только в роли исполнителей. В квесте задействовано около 16 электромагнитов, роллета, стробоскоп, ультрафиолетовая лампа, около 15 LED лент освещения. Использование оборудования, подключенного к сети 220В сведено к минимуму. В `/sketches` лежат файлы проектов для Platformio VS code.

## Node Red

В каталоге `automations/node-red` есть файл `flows.json` для импорта конфигурации проекта. Вся логика реализована на нодах для быстрых правок и управлением через Dashboard в HA через MQTT ардуино-исполнителями. Так же через node-red происходит вывод звука в квест, для включения треков и записей голосовых.

Для импорта нужен аддон - https://flows.nodered.org/node/node-red-contrib-state-machine

## Walkie receiver

Кастомное приложения для Home assistant, полностью написанное ИИ. Принимает звук с ESP32-рации и играет через общий аудио Home Assistant. Поддерживает управление громкостью с помощью MQTT. В каталоге `automations/walkie_receiver` файлы аддона, для установки скопировать их в каталог `/addons` на распберри и активировать аддон.

## Config

Для управления квестом сделана панель управления, её код лежит в `dashboard.txt`.
Файлы конфигурации `yaml` home assistant лежат в каталоге `automations/yaml`.
