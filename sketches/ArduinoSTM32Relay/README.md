# Light Control
## Описание

Данный скетч управляет релейными модулями в квеструме, к которым подключены электромагниты, УФ лампа, стробоскоп и ролетой. Общение с Home Assistant происходит по сети с помощью MQTT.


## Hardware

- **Arduino Nano** — основа проекта и управление модулями.
- **W5500 Ethernet module** — подключение к сети для общения по MQTT.
- **Модули реле** — два модуля реле на 8 каналов и один на 4 канала, обязательно с перемычкой JD-VCC, для подлкючения раздельного питания.

| W5500 | Пины |
| :---: | :--: |
| MISO  | PA6  |
| MOSI  | PA7  |
|  CLK  | PA5  |
|  CS   | PA4  |
|  RST  | PA3  |

## MQTT

```
rls/status - статус устройства (online/offline)
rls/commands - команда ВКЛ/ВЫКЛ. Формат - mXXvY, XX - номер реле (1-18), Y - 0/1
rls/status/r## - статус реле (0/1)
```
