#  RFID Toys
## Описание

Данный скетч производит чтение NFC меток спрятаных в фигурках, к ардуине подключены четыре модуля NFC по SPI. Отправляет по MQTT результат чтения модулей NFC. Также выполняет чтение по UART с ардуины которая находиться в стационарном телефоне, с её приходит четырёхзначный номер, набранный игроками. Так же на её отправляються команды ВКЛ/ВЫКЛ светодиод на телефоне.

## Hardware

- **Arduino Nano** — основа проекта и управление модулями.
- **W5500 Ethernet module** — подключение к сети для общения по MQTT.
- **PN532 x4** — SPI модуль чтения NFC карт, используется software SPI.

| W5500 | Пины |     | PN532 | Пины |
| :---: | :--: | :-: | :---: | :--: |
| MISO  | D12  |     | MISO  |  D4  |
| MOSI  | D11  |     | MOSI  |  D3  |
|  CLK  | D13  |     |  CLK  |  D5  |
|  CS   | D10  |     |  CS1  |  D7  |
|       |      |     |  CS2  |  D8  |
|       |      |     |  CS3  |  D9  |
|       |      |     |  CS4  | D10  |

## MQTT

```
toys/status - статус устройства (online/offline)
telephone/status - четырёхзначная комбинация номера, отправленная с телефона
toys/status_boards/b# - результат чтения (0-255, только третьего бита карты, уже не помню почему только его)
toys/script - комманды для светодиода (1/0)
```
