#  Telephone
## Описание

Данный скетч производит с матричной клавиатуры стационарного телефона, так же подключена кнопка сброса трубки. Игрокам нужно ввести любой четырёхзначный номер, он отправиться по UART на ардуину RFID Toys, далее комбинация будет отправлена по MQTT. К ардуине также подключены два светодиода (красный/зеленый) и реализован гудок в трубке с помощью функции `tone()`.

## Hardware

- **Arduino Nano** — основа проекта и управление модулями.
- **Стационарный телефон** — считывание кнопок.

| ROWS | COLS |     | Pins | Назначение              |
| :--: | :--: | --- | ---- | ----------------------- |
|  D5  |  D9  |     | D11  | Кнопка сброса трубки    |
|  D4  |  D8  |     | D14  | Зеленый светодиод +     |
|  D3  |  D7  |     | D15  | Красный светодиод +     |
|  D2  |  D6  |     | D12  | Вывод на динамик трубки |
