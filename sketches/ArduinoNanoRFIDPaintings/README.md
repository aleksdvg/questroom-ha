#  RFID Paintings
## Описание

Данный скетч производит чтение NFC карт спрятаных в картинах, отправляет по MQTT результат чтения модулей NFC, обновляеться каждую секунду.

## Hardware

- **Arduino Nano** — основа проекта и управление модулями.
- **W5500 Ethernet module** — подключение к сети для общения по MQTT.
- **PN532 x2** — SPI модуль чтения NFC карт, используется software SPI.

| W5500 | Пины |     | PN532 №1 | Пины |     | PN532 №2 | Пины |
| :---: | :--: | :-: | :------: | :--: | :-: | :------: | :--: |
| MISO  | D12  |     |   MISO   |  D4  |     |   MISO   |  D4  |
| MOSI  | D11  |     |   MOSI   |  D3  |     |   MOSI   |  D3  |
|  CLK  | D13  |     |   CLK    |  D5  |     |   CLK    |  D5  |
|  CS   | D10  |     |    CS    |  D7  |     |    CS    |  D8  |
|  RST  |      |     |   RST    |      |     |   RST    |      |

## MQTT

```
paintings/status - статус устройства (online/offline)
paintings/p# - результат чтения (0-255, только третьего бита карты, уже не помню почему только его)
```
