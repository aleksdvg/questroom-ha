# Walkie Radio
## Описание

Данный скетч написан полностью ИИ. Подключается к WiFi и держит постоянное MQTT-соединение с Home Assistant. При нажатии кнопки - подключается по обычному TCP к аддону на Raspberry Pi (порт 8765) и льёт сырой PCM-звук с микрофона, при отпускании - закрывает соединение. Усиление микрофона регулируется на лету через MQTT (без перепрошивки).

Цель проекта - сделать простое и мобильное устройство для вывода звука с микрофона в аудио систему квеста, чтобы можно было в любой момент дать игрокам подсказки.

Светодиод SK6812 показывает статус:
 *       КРАСНЫЙ   - нет WiFi или нет MQTT (что-то не так с сетью)
 *       ЗЕЛЁНЫЙ   - всё подключено, ждём нажатия кнопки
 *       ОРАНЖЕВЫЙ - кнопка нажата, идёт передача звука

## Hardware

- **ESP32 devkit v1** — основа проекта и управление модулями.
- **INMP441** — модуль цифрового I2S микрофона, L/R на землю вывод.
- **SK6812** — RGB светодиод Neopixel.
- **Тактовая кнопка** — самая обычная и простая кнопка.

| INMP441 | Пины |     | SK6812 | Пины |
| :-----: | :--: | --- | :----: | :--: |
|   WS    |  25  |     |  DIN   |  2   |
|   SCK   |  26  |     |        |      |
|   SD    |  32  |     | Кнопка |  27  |

## MQTT

```
walkie/status - статус устройства
walkie/talking - статус разговора (ON/OFF)
walkie/mic_gain/set - усиление микрофона (10-16, на 13 всегда норм)
walkie/mic_gain/state - текущее значение усиления
```
