# Light Control
## Описание

Данный скетч управляет освещением в квеструме и производит чтение датчиков, герконов и концевых выключателей. Общение с Home Assistant происходит по сети с помощью MQTT.

## Hardware

- **Arduino Nano** — основа проекта и управление модулями.
- **W5500 Ethernet module** — подключение к сети для общения по MQTT.
- **PCA9685** — I2C модуль ШИМ на 16 каналов, обеспечивает управление LED лентами. 
- **CD74HC4067 module**  — чтение различных датчиков, герконов и концевых выключателей.
- **MOSFET LR7843 x16**  — модуль MOSFET с опторазвязкой, управляет  яркостью LED ленты.

## MQTT

```
pwm/status - статус устройства (online/offline)
pwm/commands/b## - команда ВКЛ/ВЫКЛ свет (0/1)
pwm/brightness/b## - команда задать уровень яркости (0-255)
pwm/status/b## - статус освещения (0/1)
pwm/status_br/b## - статус яркости освещения (0-255)
pwm/script - топик для включения скриптов эффектов освещения
mux/status/b## - вывод значения датчиков (0/1)
```
